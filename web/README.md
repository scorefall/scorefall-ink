# ScoreFall™ Ink Web

Web UI for ScoreFall™ Ink.

## Developing

### Prerequisites

```shell
cargo install wasm-bindgen-cli --locked
cargo install wasm-snip --locked # currently not used
cargo install wasm-opt --locked
```

### Build and Start Webserver

```shell
cd web
./debug.sh
```

### Build Release

```shell
./release.sh
```
